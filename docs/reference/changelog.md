# 版本更新记录

FlowMaster 遵循三段式语义化版本规范，版本号唯一来源为仓库根目录 `VERSION` 文件。

## v2.5.2 (2026-11-26)

### 后台菜单结构拆分与升级防缓存修复
- **后台「系统设置」与「系统日志」独立拆分**：原「安全与系统日志」拆分为独立的 **「系统设置」**（包含站点标题、开启主控模式开关、主控公网接入地址、全站密码保护、保留上限及密码修改）与 **「系统日志」**（专页大视野倒序查看 `system`/`alert` 通道日志）。
- **彻底解决升级后旧前端缓存问题**：后端对 `index.html` 强化下发 `Cache-Control: no-store, no-cache, must-revalidate` 与 `Pragma: no-cache`，升级后刷新即加载最新界面。
- **官方静态文档站上线**：新增基于 VitePress 的 `docs/` 静态文档站并适配 Cloudflare Pages 自动同步部署。

## v2.5.1 (2026-11-26)

### 主控模式显式开关、国内直连通知与默认二进制部署
- **主控模式显式开关**：后台「安全与系统日志」新增 **「开启主控模式（Hub 多机管理中枢）」** 开关；普通单机与被控节点默认关闭，界面彻底隐藏多机总览、添加节点、分组管理与集群告警菜单；已有节点的旧版主控升级后自动延续开启。
- **企业微信机器人 & 飞书机器人通知**：新增国内直连首选的企业微信群机器人与飞书自定义机器人（支持可选 HMAC-SHA256 签名校验与业务码核验），凭据只写不回显并自动日志脱敏。
- **主控多架构安装包自动保留**：开启主控模式后，后台自动预缓存 `linux/amd64` 与 `linux/arm64` 双架构安装包至 `DATA_DIR/dist-cache/`，后台「节点与分组」可实时查看状态并一键手动同步。
- **默认推荐静态二进制部署 & 保留数据卸载**：`install.sh` 菜单与文档将静态二进制设为第一推荐；卸载操作展示保留目录清单并二次确认，完整保留数据库、配置与 `/var/lib/vnstat`。

## v2.5.0 (2026-11-26)

> 版本号按规范跳过含数字 `4` 的 `2.4.0`。

### 主控受控批量管理与远程运维（零 RCE 白名单架构）
- **多机勾选批量操作栏**：管理员在卡片墙与对比表格多选节点，一键批量改分组、批量下发月度流量包配额、批量平滑重启、批量远程升级与批量删除残留节点。
- **免 SSH 远程日志与备份直下**：节点配置弹窗新增远程脱敏运行日志查看与远程 SQLite 一致性快照直下到本地（上限 12 MiB，附 SHA-256 头）。
- **主控统一集群告警托管**：在主控配置一次即可统一监控全集群节点掉线/恢复、远程流量配额预警/超限与硬盘/内存高水位。

## v2.3.1 (2026-11-26)

### 访客隐私收敛与多机体验优化
- **访客模式脱敏**：未登录访客访问多机总览时自动脱敏服务器 IP、MAC、主机名与端口，禁止未登录下钻查看远程节点详情，前端同步隐藏管理入口。
- **多项体验与性能优化**：单机详情公网 IPv4 优先、多机对比新增 CPU/内存维度、多机偏好持久化、切换节点即时清态、远程节点今日/本月复用心跳汇总、已删除节点 `401` 自动 60s 退避。

## v2.3.0 (2026-11-25)

### 主机 CPU / 内存 / 硬盘实时监控
- 零外部依赖纯 Go 采集 Linux `/proc/stat`、`/proc/meminfo` 与根分区空间，在多机总览与单机详情页实时展示硬件负载与状态进度条。
