# 多机集群与主控分发（1 Hub + N Agents）

FlowMaster 采用同体合一架构，可将一台公网可达的机器设为主控中心（Hub），集中纳管几十上百台海内外 VPS（支持 NAT 机器与纯 IPv6 节点）。

---

## 一、开启「主控模式」

为保持普通单机与被控节点的界面清爽，**默认新装实例关闭主控模式**。

1. 在准备作为主控的服务器上完成部署并登录管理员账号；
2. 打开 **「⚙️ 本机后台 → 安全与系统日志」**；
3. 勾选 **「开启主控模式（Hub 多机管理中枢）」**；
4. 建议填写 **「主控公网接入地址」**（如 `https://hub.example.com` 或 `http://公网IP:10089`，国内机器较多时推荐填写不套 CDN 的直连域名），点击保存。

::: tip 旧版主控平滑升级兼容
如果你的主控此前已经注册过被控节点，升级到 `v2.5.1+` 后系统会自动识别并延续开启主控模式，无需手动重新开启。
:::

---

## 二、主控多架构安装包自动保留与分发

开启主控模式后，主控会立即在后台异步拉取、校验并持久化保留 **`linux/amd64`** 与 **`linux/arm64`** 两种架构的静态二进制归档及 `SHA256SUMS` 至 `DATA_DIR/dist-cache/v<版本>/`：

- 同架构节点：直接由主控自身二进制零外网打包分发；
- 异构架构节点（例如 ARM64 主控管理 AMD64 国内小鸡）：直接从主控本地已缓存的对应架构包满速下发，**被控机全程无需访问 GitHub 或任何第三方公共代理**；
- 在后台 **「节点与分组」** 顶部可实时查看 `linux/amd64` 与 `linux/arm64` 的缓存就绪状态与体积，并支持一键点击 **「同步全架构安装包」**。

---

## 三、一键添加被控节点

1. 切换到顶栏 **「🌐 多机总览」**，点击 **「+ 添加服务器节点」**；
2. 输入节点显示名称、分组标签（如 `香港 CN2`、`美国甲骨文`）与备注；
3. 保持默认勾选 **「由本主控机直接分发安装脚本与二进制包（免连 GitHub）」**（如需从 GitHub / 公共代理下载可取消勾选）；
4. 复制生成的一键接入命令并在目标被控机执行：

```bash
curl -fsSL 'https://主控地址/api/v1/cluster/dist/install.sh?token=fm_专属节点密钥' -o install.sh && \
chmod +x install.sh && sudo ./install.sh join --hub 'https://主控地址' --token 'fm_专属节点密钥' --mirror-hub --name '香港-HK1'
```

- 默认保留被控机本地 `10089` 独立面板并自动放行防火墙；若希望纯无端口探针运行，可复制弹窗中附带 `--no-web` 的命令。
- 若从主控删除了某个节点，被控端收到主控 `401` 后会自动将心跳退避至每 60 秒一次，不会在原机器产生重复进程，也不会刷爆主控日志；如需重新纳管，直接再次执行新生成的 `join` 命令覆盖更新配置即可（仅运行单个实例）。

## 四、多选批量管控与免 SSH 远程运维（零 RCE 安全设计）

登录管理员后，在 **「🌐 多机总览」** 的卡片墙或对比表格中勾选任意节点，顶部自动展开批量操作栏：

| 操作 | 说明 | 安全保障 |
| :--- | :--- | :--- |
| **批量改分组** | 一键调整选中节点的分组标签 | 仅修改主控元信息 |
| **批量下发配额** | 并发将月度流量包模板推送至多台在线节点 | 走加密长轮询隧道写入节点 SQLite |
| **批量平滑重启** | 优雅刷盘退出并由 `systemd` / Docker 自动拉起 | 严格白名单动作 `restart_service`，无需 root |
| **升级选中 / 统一远程升级** | 优先从主控下载新包校验 `SHA256SUMS` 并原子自升级 | 换包前执行 `--version` 架构预检，失败自动中止 |
| **批量删除** | 批量清理重复添加或未安装的残留节点 | 强制二次确认 + 审计日志，不破坏目标机本地数据 |

在任意节点的 **「配置」** 弹窗中，还支持两项免 SSH 诊断能力：
- **远程节点脱敏运行日志**：通过反向隧道倒序查看目标节点的 `system` 与 `alert` 通道日志；
- **远程备份直下**：远程触发目标节点执行 SQLite `VACUUM INTO` 一致性快照，经加密隧道校验后直接下载 `.tar.gz` 到本地浏览器（单次上限 12 MiB，附带 `X-Checksum-Sha256` 校验头）。

::: info 严格零 RCE 安全边界
FlowMaster 被控端**绝不开放任意 Shell 命令执行接口**，且默认以非特权 `flowmaster` 系统账号（`NoNewPrivileges=true`、`ProtectSystem=strict`）运行。即使主控会话泄露，攻击者也无法向被控机下发任意系统命令。
:::
