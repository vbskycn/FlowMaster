# 月度配额与多通道告警

FlowMaster 内置面向 VPS 流量包的月度计费周期统计，以及四通道外部告警推送与主控统一集群巡检。

---

## 一、VPS 月度流量包配额

进入 **「⚙️ 本机后台 → 月度配额与告警」**（或在主控中通过节点「配置」/「批量下发配额」远程设置）：

- **监控目标网卡**：支持绑定指定物理网卡、跟随默认主网卡，或汇总全部可见网卡（`__all__`）。
- **每月账单重置日**：支持 `1 ~ 31` 号（遇到 2 月 28/29 天或小月 30 天时自动按月末收敛对齐）。
- **4 种计费统计方向**：
  - `both`：双向合计（下行 RX + 上行 TX）
  - `tx`：仅计出站上行（适合按出站流量计费的云厂商）
  - `rx`：仅计入站下行
  - `max`：单向取较大值 `max(RX, TX)`
- **周期末预测**：根据本周期已过去天数实时推算周期末预计总消耗。

## 二、四通道外部告警推送（密钥只写不回显）

考虑到国内服务器通常无法直连 Telegram，FlowMaster 原生内置 4 种通知通道，可按需同时启用多个：

### 1. 企业微信群机器人（国内直连首选）
1. 在企业微信群聊中点击「添加群机器人」，复制生成的 Webhook 地址：
   `https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxxxxx`
2. 填入后台 **「企业微信群机器人 Webhook URL」** 并保存。
3. 发送时服务端会校验返回体 `errcode == 0`，若群机器人被禁用或限频会在 `alert` 日志通道记录精确错误码。

### 2. 飞书自定义机器人（国内直连首选）
1. 在飞书群设置 →「群机器人」→「添加自定义机器人」，复制 Webhook 地址：
   `https://open.feishu.cn/open-apis/bot/v2/hook/xxxxxx`
2. 如在飞书机器人安全设置中开启了 **「签名校验」**，将生成的签名密钥填入后台 **「飞书机器人签名校验密钥」**（FlowMaster 会按飞书规范自动计算 `HMAC-SHA256(timestamp + "\n" + secret)` 并附带 `timestamp` 与 `sign`）。
3. 服务端校验返回体 `code == 0`，密钥与 Webhook 地址均只写不回显且日志自动脱敏。

### 3. Telegram Bot
1. 通过 `@BotFather` 创建机器人获取 `Bot Token`，获取目标群组或个人的 `Chat ID`（如 `-100123456789`）。
2. 分别填入后台 **Telegram Bot Token** 与 **Telegram Chat ID**。

### 4. 通用自定义 JSON Webhook
向任意 HTTP/HTTPS 地址 POST JSON 负载（若配置了签名密钥，将附加 `X-FlowMaster-Signature: sha256=<HMAC-SHA256>` 请求头）：

```json
{
  "event": "quota_warning",
  "title": "⚠️ FlowMaster 流量已达预警线 (80%)",
  "text": "...",
  "content": "...",
  "msgtype": "text",
  "timestamp": "2026-11-26T08:00:00+08:00",
  "quota": { "...": "..." }
}
```

配置完成后点击 **「发送测试通知」** 即可验证全部已启用通道的连通性。

## 三、主控统一集群告警托管

在开启 **「主控模式」** 后，后台「月度配额与告警」会自动出现 **「多机集群统一告警托管」** 面板——**只需在主控配置一次企业微信 / 飞书 / Telegram / Webhook，即可免去几十台节点逐一配置**：

| 巡检维度 | 默认策略 | 说明 |
| :--- | :--- | :--- |
| **节点掉线与恢复上线** | 宽限 60 秒（可调 30~3600s） | 心跳中断超过宽限即发送掉线告警，恢复在线后自动发送恢复通知 |
| **远程节点流量配额** | 12 小时防抖去重 | 任意远程节点达到预警百分比或 100% 限额时由主控统一推送 |
| **硬盘 / 内存高水位** | 默认 90%（填 `0` 关闭，6 小时去重） | 任意节点（含主控本机）根分区硬盘或内存占用超阈值即预警 |

## 四、防 SSRF 安全保护

所有告警外部请求默认启用严格防 SSRF 策略：
- 禁止自动跟随 HTTP 301/302 重定向（防止经公网 URL 跳转到云元数据 `169.254.169.254`）；
- Dial 层校验解析出的真实目标 IP，默认拒绝回环、私有局域网与链路本地地址；
- 仅当明确勾选 **「允许推送至局域网私有 IP Webhook」** 时，才放行内网自建回调地址。
